# 🧠 JS Challenges

## This is my personal challenges to improve my JavaScript fundamentals

A collection of beginner-friendly JavaScript exercises focused on core programming concepts — no fancy libraries, just pure JS logic.

---

## 📂 Challenges

| File | Topic | Key Concepts |
|------|-------|--------------|
| `challenge1.js` | Grade Classifier | Variables, `if/else`, comparison operators |
| `challenge2.js` | Shopping Cart Calculator | Arrays, objects, `for` loop, arithmetic |
| `challenge3.js` | FizzBuzz | Loops, modulo `%`, conditionals |
| `challenge4.js` | Cart Summary | Objects, arrays, `for` loop, tracking max values |
| `challenge5.js` | Order Calculator | Functions, parameters, `return`, discount logic |
| `challenge6.js` | User Validator | Functions, arrays, `push()`, `includes()`, validation |
| `challenge7.js` | Product Data Transformation | `map()`, objects, discount rules, immutability |

---

## 🚀 How to Run

Make sure you have [Node.js](https://nodejs.org) installed, then run any challenge:

```bash
node challenge1.js
node challenge2.js
# ... and so on
```
